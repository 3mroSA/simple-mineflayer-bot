# Minecraft Bot

A basic Minecraft bot built with Mineflayer that connects to a server and supports simple commands made by me (3mro)

## Requirements

* Node.js (v18+ recommended)

## Installation

To install it, run the following command in the terminal:

```bash
npm install
```

## Running

Before running, you should check the server and account info in the `bot.js` file.

After doing so and verifying the server info you are now able to run the script.

If you are testing locally, you may use a cracked account by replacing the `auth` method to `offline`.

To run the script, type this in the terminal:

```bash
node bot.js
```

## First time use

If you run the script for the first time, you will get a message asking you to authenticate.

Open the link it provides and enter the code given to authenticate the script.

After you've authenticated, you may return to the script and run the `restart` command in the terminal. (or just restart the script)

## Commands

This bot has many commands, such as:

```text
restart - Restarts the bot
status - Displays bot status
say <message> - Sends a message
move <direction> - Moves the bot in a specific direction (forward, back, left, right, jump)
chat - Enables and disables reading chat (Default enabled)
guiRead - Reads the current GUI
click <slot> - Clicks on a specific slot in a GUI
botinfo - Displays bot info
goto <ip:port> - Goto a specific server
forceRestart - Restarts the bot forecfully
uptime - Displays the bot's uptime
help - Displays the command list
```

You can run these commands after starting the bot.
